Advisory Panel · Evacuation Assignment Engine

Click a village. Get the evacuation plan.
Hungarian Algorithm. Sphere-verified. Instant.

Clicking any RED/ORANGE habitation card in the sidebar triggers the Carrying Capacity Engine. It runs scipy linear_sum_assignment — the Hungarian Algorithm — to find the optimal safe zone assignment. Capacity-constrained, weighted by real OSMnx road distance. Shows the assigned camp, distance, resource pack (tents, water, food), and generates the PDF mandate in one more click.

Layer 3 · ONNX Computer Vision Pipeline

Road blocked. Route recalculated.
Three models. Parallel inference. Automatic rerouting.

Siamese change-detection model compares pre/post satellite images pixel-by-pixel (damage: minor/moderate/severe). SegFormer maps live flood extent. ResNet50 U-Net detects active landslide zones. All three run via asyncio.gather — dominated by the slowest model, not the sum. Damaged road edges removed from OSMnx graph → Layer 2 reassigns instantly.

Siamese damage detection SegFormer flood segmentation ResNet50 landslide U-Net OSM building overlay Auto rerouting

3D Simulation · Self-Calibrating System

Each monsoon makes DISHA smarter.
Calibration loop. Every event logged. Models improve.

The 3D disaster growth simulator visualises inundation spread in real time. After every monsoon cycle, Layer 3's actual damage detections are compared against Layer 1's pre-season risk predictions. Prediction errors are logged to calibration.sqlite and used to retrain the regional XGBoost models — the system gets more accurate every year, automatically.
